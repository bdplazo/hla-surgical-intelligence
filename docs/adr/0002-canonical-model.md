# ADR 0002 — Canonical contracts and hospital mappings

## Status
Accepted as initial design; implementation follows phase gates.
## Context
Equivalent RFID semantics arrive under heterogeneous field names.
## Decision
Version a canonical model and reviewed hospital-specific YAML mappings.
## Alternatives considered
One-off scripts per hospital or permissive schema-free events.
## Consequences
Central deterministic rules and traceability; explicit migration work.
## Risks
Incorrect semantic mapping or unreliable source identity.
## Revisit criteria
Validated source requirements reveal an incompatible contract.
